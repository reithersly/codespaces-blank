# Codespaces Blank

A blank HTML project template for quick web development in GitHub Codespaces.

## Description

This is a minimal starter template designed for building HTML-based web projects. Perfect for learning web development, prototyping ideas, or starting a new web project with a clean slate.

## Features

- Clean, minimal HTML structure
- Ready to use in GitHub Codespaces
- Lightweight and easy to customize
- Perfect for beginners and quick prototypes

## Getting Started

### Prerequisites

- A web browser (Chrome, Firefox, Safari, Edge, etc.)
- GitHub Codespaces or a local code editor

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/reithersly/codespaces-blank.git
   ```
2. Navigate to the project directory
   ```bash
   cd codespaces-blank
   ```
3. Open `index.html` in your web browser

## Usage

Edit the HTML files to create your web content. You can add CSS and JavaScript files as needed.

```
Example file structure:
├── index.html
├── styles.css
├── script.js
└── README.md
```
